Learning Web Design

Web design combines structure and style to create websites that are organized, readable, and easy to use. This page demonstrates some of the HTML and CSS concepts I have been learning.

HTML

HTML provides the structure of a webpage. Elements such as headings, paragraphs, links, sections, and lists organize the content displayed in a browser.

CSS

CSS controls the appearance of HTML elements. It can change colors, fonts, spacing, borders, and the overall layout of a webpage.

CSS Grid

CSS Grid is a layout system that arranges content into rows and columns. The topic cards on this page use Grid to create an organized layout.

Responsive Design

Responsive design allows a webpage to adjust to different screen sizes. Media queries can change the layout for smaller devices such as phones and tablets.

What I Have Learned

  • How HTML organizes webpage content
  • How CSS changes the appearance of a webpage
  • How CSS Grid creates rows and columns
  • How media queries make a website responsive
